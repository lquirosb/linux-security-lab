# Linux Security Lab

A hands-on cybersecurity lab for learning Linux administration, system security, networking, and security hardening.

## Objectives

- Learn essential Linux commands
- Understand users, groups, and file permissions
- Practice Linux system administration
- Analyze processes, services, and network connections
- Apply basic security hardening techniques
- Document security findings and lessons learned

## Technologies

- Linux
- Bash
- Git
- GitHub
